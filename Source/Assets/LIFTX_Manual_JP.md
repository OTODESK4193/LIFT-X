## 1. まずは音を出す

**OTODESK / ライザー専用MIDIシンセサイザー（VST3 / Standalone）**

LIFT-X は「つなぎ」を作るための楽器です。31系統のマルチポイント・エンベロープが、ピッチ・レベル・デチューン・スプレッド・フィルター・FXを同時にスイープさせ、DAWのトランスポートに同期して進行します。プリセット70種、スケール量子化用の音階70種、DAWへのドラッグ＆ドロップ書き出しを備えています。

### インストール

1. `LIFT-X.vst3` を以下にコピーします。
   ```
   C:\Program Files\Common Files\VST3\
   ```
2. DAW でプラグインを再スキャンします。

### 最初の一歩

1. インストゥルメントトラックに LIFT-X を読み込み、**PRESET** タブを開きます。
2. **EDM → Classic Saw Riser** あたりを選び、**Close** を押します。
3. DAWを再生し、MIDIノートを4小節ぶん押さえます。

**BARS** で設定した長さをかけて、Start Key から End Key へライザーが駆け上がります。PROGRESSバーが進行状況を示します。

> **MIDIノートはトリガー専用です。** どの鍵盤を押しても音程は変わりません。音程は各オシレーターの Start Key / End Key で決まります。ライザーの間はノートを押さえ続けてください（離すとリリースに入ります）。

> **音が出ない・進まないとき：** AUTOモードではDAWが再生中でないとプレイヘッドが進みません。停止中に試すときは **LIFT: AUTO** を **LIFT: MANUAL** に切り替え、LIFTノブを手で回してください。

## 2. 画面の構成

ヘッダーには **LIFT: AUTO / MANUAL** トグル、6つのタブ、右側にプリセット送り（◀ 名前 ▶）があります。

| タブ | 内容 |
|---|---|
| **MAIN** | LIFT / BARS / REVERSE / RANDOM / ATTACK / RELEASE、進行と波形、OSC1-3、ノイズ、マスター |
| **OSC ENV** | OSC1-3 と ノイズ の Pitch / Level / Detune / Spread カーブ |
| **FILTER** | フィルター4基、ソース別ルーティングとカットオフカーブ |
| **FX** | 5スロットのチェーン、エフェクト毎のソース別ルーティング、各パラメーターとカーブ |
| **PRESET** | 3カラムブラウザ（カテゴリ / サブカテゴリ / プリセット一覧） |
| **CONFIG** | スケール量子化、マスターリミッター、カラーテーマ |

### いちばん大事な考え方

**LIFT はプレイヘッドです。** 0〜1の位置を示すもので、プラグイン内の*すべての*カーブがこの同じ位置で読まれます。

* **AUTO** — BARS で決めた長さをかけて、DAWのトランスポートに追従して進みます。LIFTノブは自動で動き、手では回せません。
* **MANUAL** — LIFTノブ*そのもの*がプレイヘッドです。68%で止めればその瞬間の音が保持されます。非線形なタイミングにしたいときは、このモードでDAWからオートメーションしてください。

## 3. MAIN タブ

<img src="Main.jpg" width="700">

### グローバル

| コントロール | 内容 |
|---|---|
| **LIFT** | プレイヘッド位置 0〜100% |
| **BARS** | 1回のスイープにかける長さ：1/32, 1/16, 1/8, 1/4, 1/2, 1, 2, 4, 8, 16小節 |
| **REVERSE** | 31系統すべてのカーブを逆から読む。ライザー↔ダウナーが入れ替わる |
| **RANDOM** | MAIN と OSC ENV を音楽的な範囲でランダマイズ。Master / FX / Filter / Config には触れない |
| **ATTACK** | 0.1〜500ms |
| **RELEASE** | 5〜4000ms |
| **PROGRESS** | 時間軸の進行。REVERSE時も常に 0→100% |
| **波形ストリップ** | 録音されたライザー。**DAWへドラッグ**すると32bit float WAVとして書き出せます |

> **REVERSE と Start/End の入れ替えは違います。** 手動でキーを入れ替えることもできますが、REVERSE はフィルタースイープもFXカーブもレベルの形も同時に反転します。ジェスチャー全体が裏返るので、ダウナーらしい説得力が出ます。

### オシレーター 1-3

| コントロール | 内容 |
|---|---|
| **OSC n / S / M** | 有効化 / ソロ / ミュート |
| **波形メニュー** | Sine, Triangle, Square, Saw, FM, Wavetable |
| **波形表示** | 現在の波形とモーフ位置のプレビュー |
| **BROWSE / RND** | カスタムWavetableの読み込み、またはランダム選択 |
| **POS** | Wavetable内のモーフ位置（Wavetableモード時） |
| **LEVEL** | 0〜100% |
| **COARSE** | −24〜+24半音。スケール量子化の*後*に加算されます |
| **UNISON** | 1〜7ボイス |
| **DETUNE** | 0〜100セント |
| **SPREAD** | ユニゾンボイスのステレオ幅 |
| **PITCHレール** | 現在のピッチを音名で表示。量子化時はスケール構成音の目盛りが出ます |
| **ST / END** | Start Key / End Key。クリックしてから鍵盤を押して設定 |

> **音域の設定：** **ST** をクリック → ライザーを始めたい音を鍵盤で押す → **END** をクリック → 到達させたい音を押す。もう一度ボタンを押すと解除されます。

### ノイズ

White / Pink / Brown をバンドパスフィルターに通します。**PITCH**（中心周波数）、**RES**（Q）、**RANGE**（ピッチカーブが何オクターブ動くか）を個別に設定できます。

### マスター

**OUT** は最終出力レベル、**CEILING** は CONFIG タブのリミッター天井と連動しています。

## 4. OSC ENV タブ

<img src="OSCEnv.jpg" width="700">

オシレーター1基につき4本、ノイズに3本、合わせて15本のカーブをこのタブで編集します。

| 行 | 選択肢 | 意味 |
|---|---|---|
| ソース | OSC 1 / OSC 2 / OSC 3 / NOISE | 編集対象 |
| ターゲット | PITCH / LEVEL / DETUNE / SPREAD | 対象パラメーター（ノイズは PITCH / LEVEL / RES） |

### カーブの読み方

* **PITCH はユニポーラ**：グラフの**下端が Start Key、上端が End Key** です。左下から右上への直線が、いちばん素直な直線ライザーになります。
* **それ以外はバイポーラ**：**中央線が現在のノブ値**で、上へ描くと最大方向、下へ描くと最小方向へ動きます。中央でまっすぐなら変調なしです。

### 編集操作

| 操作 | 結果 |
|---|---|
| **ポイントをドラッグ** | 移動 |
| **空白をダブルクリック** | ポイント追加 |
| **ポイントをダブルクリック** | ポイント削除 |
| **区間のひし形をドラッグ** | その区間のカーブ（テンション）を曲げる |
| **CURVES** | 28種のプリセット形状、「Save Current…」、保存済みユーザーカーブ |
| **SNAP** | ポイントのX座標を 4/8/16/32/64 分割グリッドに吸着 |

28種の内訳：Linear Up/Down、Exp と Log の上下、S-Curve 上下、Ramp+Hold、Hold+Ramp、Triangle、V Shape、**Steps 4/8/16/32**、**Saw 4/8/16/32**、**Pulse 4/8/16/32**、Zigzag Up、Flat Center、Flat Max。

> **リズミカルなライザーは Steps / Pulse 形状で作れます。** FXを使わなくても、Pitch に Steps 16 を当てればマシンガン的な駆け上がり、Level に Pulse 8 を当てればゲート感が出ます。

## 5. FILTER タブ

<img src="FILTER.jpg" width="700">

独立した ZDF/TPT ステートバリアブルフィルターが4基あります。

| コントロール | 内容 |
|---|---|
| **FLT 1-4** | 編集するフィルター |
| **ENABLE** | オン/オフ |
| **ROUTE** | このフィルターを通すソース — OSC 1 / OSC 2 / OSC 3 / NOISE |
| **TYPE** | LowPass / HighPass / BandPass / Notch |
| **CUTOFF** | 20Hz〜20kHz |
| **RES** | 0.5〜12 |
| **ENV AMT** | −100〜+100%。カーブがカットオフを動かす量 |

**重要なのは ROUTE です。** 各フィルターを任意のソースの組み合わせに適用できるので、「ノイズだけハイパスして、オシレーターはフルレンジのまま」「OSC1とOSC2に別々のローパスをかける」といったことができます。

カーブ × ENV AMT は ±10オクターブぶん動くため、CUTOFFノブがどの位置にあってもカーブ上端で最大値に到達します。ENV AMT をマイナスにするとスイープが反転します。

## 6. FX タブ

<img src="FX.jpg" width="700">

### CHAIN

5つのスロットを左から順に処理します。各スロットに None / Saturation / Chorus / Delay / Reverb / Ducking を割り当てるので、**かかる順番を自由に決められます**。

### ROUTE

エフェクトごとに **ROUTE: OSC 1 / OSC 2 / OSC 3 / NOISE** の行があります。**OFFにしたソースはそのエフェクトを完全にバイパスして素通し**します。チェーン単位ではなくエフェクト単位なので、「OSC1だけサチュレーション、OSC2にはコーラス、ディレイはノイズだけ」といった使い分けができます。

### 各エフェクト

| エフェクト | パラメーター |
|---|---|
| **SAT** | AMT、ALGO（Soft Tanh, Hard Clip, Triode, Tape, Transformer, JFET, BJT, Wavefold, Exciter, Cubic）、DRIVE 1〜12、PRE HPF 20〜2000Hz、TRIM ±12dB |
| **CHORUS** | AMT、RATE 0.05〜8Hz、DEPTH、WIDTH |
| **DELAY** | AMT、TIME（1/2〜1/16T、付点・三連対応）、FB 0〜95%、DUCK、DAMP |
| **REVERB** | AMT、DECAY、SHIMMER、DAMP、MOD |
| **DUCK** | AMT、RATE（1小節〜1/64）、SHAPE 0.5〜8 |

Delay と Ducking はホストのPPQに同期するため、サイドチェイン入力なしでグリッドに張り付きます。

### FXカーブ

**ENV:** サブタブでそのエフェクトのカーブを開きます。カーブ変調される12個のパラメーターはすべてバイポーラで、中央がノブ値です。Delay の **TIME** と Duck の **RATE** だけは特殊で、カーブが拍長を ±2オクターブ動かします（下へ描くほど速くなります）。

> **Delay Time のカーブを下降させる**と、エコーが加速していく定番のビルドが作れます。

## 7. CONFIG タブ

<img src="Config.jpg" width="700">

### PITCH ENV — SCALE

| コントロール | 内容 |
|---|---|
| **SCALE QUANTIZE** | OFF：カーブ通りの滑らかなピッチ変化。ON：スケール構成音へスナップ |
| **KEY** | C〜B |
| **SCALE** | 70種。カテゴリ別に分類（Basic / Modes & Variants / World / Indian / Japan・Asia / Symmetric・Bebop / Chord Tones） |
| **APPLY TO** | どのオシレーターに適用するか |

量子化をONにすると、直線的なピッチカーブが**階段状**になります。滑らかに滑るのではなく、スケールを一段ずつ登っていく動きです。COARSE は量子化の*後*に加算されるので、+12st のオシレーターは常に正確に1オクターブ上を保ちます。

KEY / SCALE / APPLY TO を変更すると、**各オシレーターの Start / End キーも最寄りの構成音へ再スナップ**されます。その後の手動編集は自由で、プリセット読込では発火しません。

> **Chord Tones 系のスケール**（Major Triad / Minor 7th / Major 9th など）を選ぶと、ピッチカーブがアルペジオになります。スイープがコードトーンだけを踏んでいきます。

### MASTER LIMITER

瞬間アタック・レイテンシ0のブリックウォール。PDC（プラグイン遅延補正）不要です。**CEILING** −12〜0dB、**RELEASE** 20〜1000ms。

### APPEARANCE

カラーテーマ10種：Midnight, Sakura, Ocean, Forest, Sunset, Mono, Neon, Vaporwave, Amber, Arctic。完全に反映するにはプラグインウィンドウを開き直してください。

## 8. プリセット

<img src="PRESET.jpg" width="700">

11カテゴリ・70種のファクトリープリセットを収録：**EDM / Trance / Bass / Techno / Cinematic / Downer / Scale Riser / Dubstep / DnB / Hardstyle / Ambient**

| 操作 | 方法 |
|---|---|
| **読み込み** | 右カラムのプリセットをクリック |
| **絞り込み** | カテゴリ（All / Factory / User / Favorites）→ サブカテゴリ |
| **検索** | 検索ボックスに入力 |
| **お気に入り** | ☆ をクリック |
| **保存** | 名前（必要ならサブカテゴリも）を入力して **Save** |
| **削除** | ユーザープリセットを右クリック |
| **Init** | すべてを初期値に戻す |
| **送り** | ヘッダーの ◀▶ で Factory と User を通しで順送り |

ユーザープリセットは `%APPDATA%\LIFT-X\Presets`、ユーザーカーブは `%APPDATA%\LIFT-X\Curves` に保存されます。

## 9. レシピ集

**定番のスーパーソウ・ライザー**
Saw、UNISON 7、DETUNE 40ct前後、SPREAD 100%。Start Key C2 / End Key C6、BARS 4。Filter 1 を LowPass、CUTOFF 600Hz、ENV AMT 80%、カーブは少し上に膨らませた上昇形。Reverb と 1/4 の Ducking を追加。

**スケールに沿った階段ライザー**
CONFIG → SCALE QUANTIZE をON、KEY を曲のキーに、SCALE を Minor Pentatonic。Square、UNISON 3、Start/End を3オクターブ離す、BARS 8。Pitch カーブを少し指数的にすると階段が加速します。1/16・FB 60% の Delay を追加。

**リズミカルな尾を持つノイズスイープ**
OSC1-3をすべてOFF。ノイズ LEVEL 90%、PITCH 250Hz、RANGE 6oct、Noise Pitch カーブを上昇させる。DELAY タブで ROUTE を NOISE のみにし、TIME 1/16、FB 60%。1/16 の Ducking を追加。

**どんなライザーからでもダウナーを作る**
好きなライザープリセットを読み込んで **REVERSE** を押すだけ。BARS を 1/2 か 1 に、RELEASE を300ms前後まで短くすると素早いドロップになります。

**階段と滑らかを重ねる**
上記の階段ライザーを OSC1 で作り、OSC2 を COARSE −12 で有効化。CONFIG → APPLY TO で **OSC2をOFF**にします。下の層は滑らかに滑り、上の層は階段を登ります。

**シネマティック・スウェル**
Saw、UNISON 7、DETUNEは控えめに。OSC3 に1オクターブ下のサイン波を追加。ATTACK 200ms、RELEASE 1200ms、BARS 8。Reverb AMT 65%、DECAY 90%、SHIMMER 50%。

## 10. 困ったときは

**音が出ない / ライザーが進まない**
AUTOモードではDAWが再生中でないとプレイヘッドが進みません。再生を開始するか、MANUALに切り替えてLIFTノブを動かしてください。

**ライザーが違う音程から始まる**
MIDIノートはトリガー専用です。音程は各オシレーターの **ST** / **END** で設定してください。別の鍵盤を押しても変わりません。

**Scale QuantizeをONにしても階段にならない**
CONFIG タブの **APPLY TO** を確認してください。聴いているオシレーターが対象外になっている可能性があります。

**Start/End キーが勝手に動いた**
KEY / SCALE / APPLY TO を変更すると、最寄りの構成音へ再スナップする仕様です。その後は手で編集すればそのまま維持されます。プリセット読込では再スナップされません。

**特定のソースにエフェクトがかからない**
そのエフェクトタブの **ROUTE** 行を確認してください。OFFのソースはエフェクトを完全にバイパスします。

**プロジェクトを開き直すとプリセット名が "Init" になる**
v0.4.0 で修正済みです。それ以前のビルドで保存したプロジェクトには名前が記録されていません。

**Wavetableが読み込み直されない**
カスタムWavetableはファイルパスで参照しています。ファイルを移動したりドライブを外したりすると、そのオシレーターは内蔵波形に戻ります。**BROWSE** から読み込み直してください。

**テーマ変更が中途半端に見える**
プラグインウィンドウを閉じて開き直してください。

**CPU負荷が高い**
ユニゾンはオシレーターのコストを倍加させます（3基×7ボイス＝21ボイス）。FXでは Reverb と Delay が最も重いです。ソース別ルーティングでコストが増えることはありませんが、使っていないスロットを None にすると軽くなります。
